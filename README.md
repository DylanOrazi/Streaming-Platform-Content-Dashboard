Streaming Platform Content Dashboard

Project Overview:
The Streaming Platform Content Dashboard is a data analytics project built with Excel, Python, and Power BI. The project analyzes a fictional streaming content dataset to compare platforms, content types, genres, popularity, views, watch hours, and completion rates.

Tools Used:
- Excel
- Python
- pandas
- Power BI
- CSV files
- Dashboard design
- Project documentation

Main Files:
- streaming_content_dataset.xlsx
- streaming_content_dataset.csv
- streaming_content_analysis.py
- streaming_content_cleaned.csv
- Streaming_Platform_Content_Dashboard.pbix
- Project Findings.txt
- README.txt

Dataset Overview:
The dataset contains 500 fictional streaming titles.

The dataset includes:
- Platform
- Title
- Content type
- Genre
- Release year
- Content rating
- Runtime
- Season count
- Country
- Language
- Audience score
- Critic score
- Popularity score
- Monthly views
- Watch hours
- Completion rate
- Subscription tier
- Date added

Python Processing:

Dashboards Created:
1. Content Library Overview
2. Viewer Engagement & Performance

Dashboard 1:
Content Library Overview

This dashboard focuses on the content catalog. It shows platform title counts, content type breakdown, release decade trends, and average popularity scores by platform.

Dashboard 2:
Viewer Engagement & Performance

This dashboard focuses on viewer activity and performance. It shows monthly views, watch hours, completion rates, top-performing titles, and audience-versus-critic score patterns.
